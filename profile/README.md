## Products

**[Iceslab](https://icecompany.tech/en/iceslab)** *(Public Alpha, v0.3, AGPL-3.0)* self-hosted proxy panel that runs every protocol on its own upstream core: Xray, sing-box, Hysteria 2, AmneziaWG, NaiveProxy, Mieru and more. Cascades, subscriptions, one agent per node.

**[Iceshard](https://icecompany.tech/en/iceshard)** *(In development)* native client for Iceslab-powered services. Hand-built in C++/Qt. Windows first, then Android, Linux, iOS, macOS.

**[Icepath](https://icecompany.tech/en/icepath)** *(In development)* consumer VPN delivered through a Telegram Mini App, built on Iceslab and Iceshard.

**[Icecore](https://icecompany.tech/en/icecore)** *(R&D)* multi-protocol proxy runtime engine. An alternative to Xray and sing-box.

**[Iceproxy](https://icecompany.tech/en/iceproxy)** *(Planning)* reverse-proxy layer. An alternative to Nginx, Caddy, and Traefik.

Iceslab and Iceshard are a closed pair, they speak only to each other. Icepath runs on top of them. Icecore and Iceproxy are independent infrastructure pieces.

## Tools

- **[iceslab-migrate](https://github.com/icecompany-tech/iceslab-migrate)** moves an existing panel's users and settings to Iceslab.
- **[iceslab-recipes](https://github.com/icecompany-tech/iceslab-recipes)** transport recipes the panel reads by default.
- **[core-builds](https://github.com/icecompany-tech/core-builds)** our signed builds of upstream cores, with recipe and upstream commit.
