# Contributing

Most repositories under github.com/icecompany-tech are private. This page applies to the public ones, primarily [Iceslab](https://github.com/icecompany-tech/iceslab).

## Before you start

Open an issue first if you plan a non-trivial change. We want to agree on direction before you spend time on a PR.

For bug reports and feature requests, use the templates on the issue tracker of the relevant repository.

## Pull requests

- Branch off `main`. Trunk-based, no long-running branches.
- One logical change per PR.
- Reference the issue you are addressing.
- Run the project's tests and linters locally before opening the PR.
- English in code, comments, and commit messages.

## Style

- No em-dash anywhere (commits, comments, code, docs). Use a hyphen, colon, or comma.
- Match the existing code style of the file you are editing. The repo's own style guide overrides anything here.

## Development setup

Each repository documents its own dev setup in its README. Start there.
